# Lumen — лаунчер Roblox на Electron (Windows)

Установщик и обновления: вкладка **Releases** этого репозитория. Установите `Lumen-Setup-x.y.z.exe`, дальше лаунчер обновляется сам
(плашка «Доступна версия…» и раздел «Обновления лаунчера» на вкладке «Лаунчер»).

## Разработка

    npm install
    npm start          # запуск из исходников (автообновление в этом режиме отключено)
    npm run dist       # локальная сборка установщика в dist/ (нужна Windows)

После первого `npm install` закоммитьте `package-lock.json`, чтобы сборки были воспроизводимыми.

## Выпуск обновления

    npm run release          # версия +0.0.1, коммит, тег vX.Y.Z и пуш
    npm run release:minor    # версия +0.1.0

Пуш тега запускает GitHub Actions (`.github/workflows/release.yml`): на Windows-раннере собирается `Lumen-Setup-x.y.z.exe`,
создаётся релиз с установщиком и `latest.yml`. Лаунчеры пользователей находят релиз и предлагают обновиться.
Описание релиза на GitHub показывается пользователям в разделе «Что нового». Тег вида `v1.2.0-beta.1` публикуется как пре-релиз.

Репозиторий должен быть публичным, иначе лаунчер не сможет читать релизы без токена.
Установщик не подписан, поэтому Windows SmartScreen при первой установке покажет предупреждение.

## Прочее

- `Lumen --play` запускает Roblox сразу, `Lumen --studio` запускает Roblox Studio.
- Данные: `%LOCALAPPDATA%\Lumen`.
- Для Discord Rich Presence нужен свой Application ID (discord.com/developers).
- FPS в оверлее требует отдельно скачанного PresentMon.
- Иконка рисуется скриптом `npm run icon` (`build/icon.ico`), замените файлы в `build/`, если нужна своя.
